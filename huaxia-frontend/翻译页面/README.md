# 翻译页面功能说明

## 功能概述

翻译页面已经完成与后端的集成，支持以下功能：

### 1. 翻译功能
- ✅ 文本输入和输出
- ✅ 字符计数（最大5000字符）
- ✅ 翻译按钮点击事件
- ✅ 流式翻译（优先）和普通翻译（备选）
- ✅ 错误处理和用户提示

### 2. 术语库选择
- ✅ UI交互（选择术语库类型）
- ✅ 调用后端API获取术语库列表
- ✅ 创建自动机（会话ID）
- ✅ 术语匹配功能

### 3. 模板选择
- ✅ UI交互（选择翻译模板）
- ✅ 调用后端API获取模板列表
- ✅ 模板应用到翻译过程

### 4. 辅助功能
- ✅ 一键清除输入输出
- ✅ 复制翻译结果
- ✅ 字符计数和验证
- ✅ 按钮状态管理

## 后端接口

### 翻译相关接口
- `POST /api/translate/automaton/create` - 创建自动机
- `POST /api/translate/custom/flux` - 流式翻译
- `POST /api/translate/custom` - 普通翻译

### 术语库接口
- `GET /api/glossary/list` - 获取术语库列表

### 模板接口
- `GET /api/template/list` - 获取模板列表

## 使用流程

1. **选择术语库**：点击术语库按钮，选择专业领域或六大板块
2. **选择模板**：点击模板按钮，选择翻译模板
3. **输入文本**：在左侧输入框输入要翻译的文本
4. **开始翻译**：点击翻译按钮
5. **查看结果**：翻译结果会显示在右侧输出框

## 技术实现

### 前端技术
- 原生JavaScript（ES6+）
- Tailwind CSS
- Font Awesome图标
- Fetch API
- Stream API（流式响应处理）

### 后端集成
- 使用 `window.CommonApi` 调用后端接口
- 支持Bearer Token认证
- 错误处理和重试机制
- 流式响应处理

## 注意事项

1. **认证要求**：需要先登录获取token
2. **字符限制**：单次翻译最多5000字符
3. **网络要求**：需要能够访问后端API
4. **浏览器兼容**：需要支持ES6+和Stream API的现代浏览器

## 测试建议

1. 先测试简单文本翻译（不选择术语库和模板）
2. 测试术语库选择功能
3. 测试模板选择功能
4. 测试长文本翻译
5. 测试错误处理（如网络断开、认证失败等）

## 故障排除

### 常见问题
1. **翻译失败**：检查网络连接和认证状态
2. **术语库加载失败**：检查后端术语库服务是否正常
3. **模板加载失败**：检查后端模板服务是否正常
4. **流式翻译失败**：会自动降级到普通翻译

### 调试信息
- 打开浏览器开发者工具查看控制台日志
- 检查网络请求状态和响应
- 查看API调用参数和返回值
